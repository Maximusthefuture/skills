### 4.3. Судья `critic-gate` (prompt-хук, Haiku), 3 повтора

| Сценарий | Ожидание | Аудит 2026-10-03 (RU, старый промпт) | RU после правок | EN |
|---|---|---|---|---|
| Патч через `git apply`, отчёт «Готово, патч применён» | block | 0/3 | **3/3** | **3/3** |
| M: новый эндпоинт `GET /orders/{id}/status` | block | 5/6 (другой сценарий M) | 1/3 | **3/3** |

| **Итого** | | | **10/12** | **12/12** |

- Правка правила 4 закрыла дыру с `git apply` в обоих вариантах. Судья прямо пишет «git apply applied a patch to production files…».
- Русский судья дважды из трёх счёл новый эндпоинт изменением размера S: «добавлен один новый метод». Английский промпт короче (598 токенов против 859) и все три раза называет новый эндпоинт изменением публичного API размера M.
- Средняя стоимость прогона ($0.07 RU, $0.09 EN) включает работу самой сессии. У EN она выше, потому что после block сессия делает лишний круг. Сам промпт судьи — малая часть запроса: судья читает всю переписку.
- Первый английский прогон шёл параллельно с другими тестами и весь упал на 429 (rate limit). Его перезапустили в 2 потока, в таблице результаты перезапуска.

### 4.4. Агенты `java-code-reviewer` + `critic` (Sonnet 5) на diff с 7 дефектами

Тот же diff «архивирование заказов», что в аудите (3.3). Оркестратор — Haiku, агенты — Sonnet 5, оба запущены параллельно.

| | RU | EN |
|---|---|---|
| Ревьюер: IDOR, статус, идемпотентность, NOT NULL → POST /orders, `findAll` без пагинации | 5/5 | 5/5 |
| Ревьюер: индекс без CONCURRENTLY, 12M строк | — | — |

| Первой строкой статус | ревьюер — да; критик — после одной строки «подтверждаю контекст» | критик — да; ревьюер — после одной строки |
| Размер отчётов (ревьюер + критик) | 4.96k + 11.1k симв., 44 + 77 строк | 6.3k + 8.4k симв., 51 + 64 строки |

Что из этого следует:
- На Sonnet качество ревью от языка инструкций не зависит.
- Разница в стоимости объясняется тем, сколько модель думала (thinking 5k против 10.6k), а не языком: инструкции агентов занимают 2–5k токенов из ~900k прочитанных.

- Лимит в 60 строк критик в русском варианте превысил (77 строк).

Английский оркестратор (Haiku) упёрся в лимит сессии подписки, когда собирал итог. Оба отчёта агентов к этому моменту были готовы и взяты из лога.

Как читать раунд 2:
- **Соблюдение процесса:** EN 2/2 по всем пунктам, RU пропустил RED в одном прогоне. Английская версия вызвала `java-tdd`, как требует фаза 4. Русская ограничилась оркестратором, хотя текст фазы 4 тот же.
- **Токены:** при почти вдвое большем объёме текста скиллов (22.6k против 12.1k символов) максимальный контекст у EN #1 такой же, как у RU (~55k). Значит, тот же набор скиллов на английском занимает примерно на 2k токенов меньше.

## 5. Не сделано, риски, рекомендации

1. **`orders-service` не собирается** (раздел 1). Нужно доделать или откатить outbox и проверить код на совместимость с Boot 3.1.5, либо поднять Boot в `pom.xml`, если 3.5.x и было целью.
2. **Нет JDK 21.** Поставить его, указать в `JAVA_HOME` или в toolchains и убрать `-Dnet.bytebuddy.experimental=true` из `.mvn/maven.config`.
3. **`mvn` не в PATH.** Скиллы и `CLAUDE.md` используют `./mvnw`, так что для агентов это не нужно. Если нужен `mvn` в терминале:
   ```bash
   echo 'export PATH="/Applications/IntelliJ IDEA.app/Contents/plugins/maven/lib/maven3/bin:$PATH"' >> ~/.zshrc
   ```
4. **Эвалы `java-dev-flow` проверены только на Haiku и по одному повтору.** Разница 19 против 20 из 22 — в пределах шума. Стоит прогнать по 3 повтора и на Sonnet.
5. **`critic` срабатывает слишком охотно** (#17). Можно уточнить его описание: «after a code change is made», а не при обсуждении.
6. **#20 (openspec)** не вызывает `java-dev-flow` ни в одном варианте. Возможно, эвал устарел: при включённом OpenSpec `openspec-propose` — законный первый шаг.
7. **Глобальный судья удалён из `~/.claude/settings.json`.** В других Java-проектах `critic-gate` теперь не работает, пока туда не скопирован `settings.example.json`.
8. **`git stash` для проверки «падало и до меня»** (раздел 4.5). Добавить запрет в `java-dev-flow` / `verify.md`.
9. **`tdd_guard` Haiku игнорирует.** Если нужна жёсткая остановка, вариант — PreToolUse-хук, который отказывает в правке `src/main/**` до красного прогона (`permissionDecision: deny`). Это строже и может мешать в рефакторинге.
10. **Лимиты API.** Параллельные прогоны (6 потоков) упёрлись в 429 и в лимит сессии подписки. Обвязка теперь по умолчанию работает в 2 потока.

## 6. Как повторить измерения

```bash
SP=<scratchpad>; export AUDIT_DIR=$SP/audit; H=audit/2026-10-04-harness
# песочница из варианта скиллов (каталог с java-dev-flow/, java-tdd/ …)

bash    $H/agents_run.sh agents-en en $AUDIT_DIR/sb-en/orders-service
WORKERS=2 python3 $H/judge_run.py en $AUDIT_DIR/sb-en/orders-service 3
python3 $H/scycle_run.py sc-en-haiku $AUDIT_DIR/sb-en/orders-service haiku 2
```

Базовая копия `orders-service` для песочниц лежит в `$AUDIT_DIR/base/orders-service`, `seed.sh` накатывает diff с дефектами для агентов.

Точный подсчёт токенов: скрипт `count.py` из scratchpad сессии. Каждый файл отправляется через stdin в `claude -p --model <m> --system-prompt "Reply with OK only." --tools "" --setting-sources ""`, из суммы `input + cache_creation + cache_read` вычитается базовый запрос с пустым документом.
