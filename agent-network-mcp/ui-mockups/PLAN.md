# Редизайн UI agent-network: «мессенджер с агентами»

Цель: сделать страницу понятной без чтения инструкций. Опора — паттерны Claude Desktop и ChatGPT: сайдбар со списком разговоров, центральная колонка-чат, карточки вместо таблиц, одно действие на экране.

## Что не так сейчас

| Проблема | Сейчас | Как у Claude/ChatGPT |
|---|---|---|
| Навигация | 12 вкладок, часть прячется в «История» | Один сайдбар, 3–4 раздела, остальное в контексте |
| Задача | Карточка, утыканная панелями, фазы аббревиатурами | Лента событий как диалог, понятными предложениями |
| Главная | Таблицы KPI + две колонки панелей | «Что ждёт меня» списком + «Что происходит» лентой |
| Новая задача | Форма на 15 полей с чекбоксами | Одно поле «опишите задачу», настройки в шторке |
| Жаргон | BLOCKED, READY_FOR_SYNC, worktree, runner | Человеческие фразы: «остановлена, ждёт вас» |

## Новая информационная архитектура

Сайдбар (как список чатов):

- **«Нужно мне»** (корень `/`) — входящие: вопросы, план на утверждение, приёмка, BLOCKED. Счётчик на бейдже. Это и есть главная.
- **Задачи** — список как чаты: аватар-статус, название, последняя реплика («backend: сделал 3/5 подзадач»), время. Группировка: «Идут» → «Ждут вас» → «В очереди» → «Готовые». Поиск сверху. Кнопка «+ Новая задача» — в шапке сайдбара.
- **Агенты** — карточки агентов, у каждого «чем занят сейчас».
- Внизу сайдбара: переключатель проекта (выпадашка), иконки «Настройки» и «Ещё».

Всё второстепенное уходит в глубину:

- Активность/Сессии/События → кнопка «Подробности» внутри задачи (открывает drawer справа).
- Надзор, Наблюдатель, Раскатка, Расписания, Проекты → страница «Настройки» со списком-меню.
- План задачи (HTML-страница плана) → открывается модалкой поверх, как сейчас `planov`, но оформлена единообразно.

## Страница задачи = чат

Центральная колонка — лента сверху вниз, автоскролл вниз:

1. **Шапка**: название, фаза словами («Проверка, раунд 2 из 3»), тонкий прогресс-бар, кнопки действий (остановить, влить, открыть diff).
2. **Сообщения-пузыри** по участникам: агент backend слева, reviewer слева, lead слева, **вы — справа**. Каждая фаза — разделитель с датой («Выполнение · началось 14:20»).
3. **Типы «сообщений»** (рендерим из существующих данных, без нового API):
   - реплика агента (из `pendingMessages`/`send_message`),
   - карточка «Agreement предложен — Утвердить / Посмотреть»,
   - карточка «План готов — Открыть и утвердить»,
   - карточка прогресса «Подзадачи 3/5» (мини-бары),
   - карточка ревью «Найдено 2 ошибки — кто исправляет»,
   - карточка приёмки с критериями и кнопкой «Принять»,
   - системная строка «task blocked: лимит $10».
4. **Поле ввода внизу**: «Написать агентам…» → `send_message` от operator. Вопросы агентов приходят как сообщение с вариантами-чипами под ним — отвечаете кликом (это существующий `options` из API).
5. «Подробности» в шапке открывают правый drawer: таймлайн активности (текущий `.act`), коммиты, скиллы, расход.

## Новая задача

Кнопка «+» в сайдбаре → полноэкранный диалог: одно большое поле «Что сделать?» с примерами-подсказками. Кнопка «Составить черновик» (существующий drafter). Под полем — свёрнутый блок «Настройки» (lead, агенты, глубина, лимит $) — значения по умолчанию уже выбраны, трогать не нужно. Submit → переход в «чат» новой задачи.

## Визуальная система

- Палитра в духе Claude: тёплый фон `#F7F5F2` / тёмный `#1B1917`, акцент терракота `#C96442`, текст графит.
- Шрифт интерфейса системный, заголовки можно Georgia/serif (как у Claude) — даёт «человечность».
- Радиусы 10–12 px, мягкие тени вместо границ-линеек, отступы 20–24 px.
- Статусы — не аббревиатуры, а точка + фраза: 🟢 «работает», 🟡 «ждёт вас», 🔴 «остановлена», ⚪ «готово».
- Плотность: одна строка = одна мысль; никаких таблиц в основном потоке (таблицы остаются только в «Подробностях» и настройках).

## План работ (по шагам)

1. **Скелет**: новый `page2.ts` рядом со старым (feature-flag `/v2`), тот же `/api/*`. Каркас: сайдбар + роутер по хешу, 4 маршрута.
2. **Входящие**: перенос `renderInbox` в новый дизайн (карточки «нужно решение» с кнопкой действия).
3. **Список задач**: сайдбар-лента из `S.tasks` (данные те же: `progressOf`, `phaseLabel`).
4. **Чат задачи**: маппер существующих событий/сообщений/прогресса в «сообщения»; поле ввода → `send_message`; кнопки утверждения плана/приёмки переиспользуют `openPlan`/`openAcceptance`.
5. **Новая задача**: диалог-мастер, внутри — существующая форма, свёрнутая в «Настройки».
6. **Агенты и Настройки**: карточки из `renderControl`/`renderAgents`; ссылки на надзор/наблюдателя/раскатку.
7. **Уведомления и тосты**: оставить механику (`watchTransitions`, `watchAttention`), переделать визуал на бейджи сайдбара + ненавязчивые тосты.
8. **Тесты**: `test/unit/pageScript.test.ts`, `ui.test.ts` — параллельный набор снапшотов/проверок для v2; старый UI доступен по `/v1`, пока v2 не покроет parity-матрицу.
9. **Переключение**: v2 по умолчанию, `/v1` — запасной вариант на 1–2 релиза.

Parity-матрица (v1 → v2) ведётся в этом файле по мере переноса — ни одна функция не должна потеряться молча.

## Ревизия 2 — упрощение и своя палитра

Упрощения (без потери функций — всё осталось, сменилось расположение):

- Сайдбар — один список задач с поиском сверху; разделители «Идут/Готовые» убраны: задачи, ждущие ответа, сами всплывают наверх с маркером «вы»; готовые — приглушённые внизу, архив за ссылкой.
- Футер сайдбара: компактная полоса (пользователь, уведомления, настройки) вместо текстового блока с путём — путь в тултипе настроек.
- Второстепенные разделы сведены к двум строкам: «Агенты» и «Архив и история»; надзор/наблюдатель/раскатка/расписания — внутри «Настроек» (иконка ⚙).
- Вопросы агентов отвечаются чипами прямо в пузыре сообщения в чате задачи — без отдельного раздела «Вопросы».
- Шапка задачи сжата до одной строки + тонкий прогресс; действия (diff, влить, остановить, подробности) — в меню «⋯».
- Агенты — компактные строки вместо карточек; скиллы/worktree свёрнуты.
- Новая задача: автофокус на поле, сводка настроек в одну строку в summary («lead backend · стандарт · без лимита»).

Палитра своя: чернильный сайдбар `#141518`, костяной фон `#F7F7F4`, акцент — лайм `#C8F169` (CTA и активные статусы), фиолет `#8B7CF6` для ревью/планов. Семантика цвета: лайм = работает/готово, янтарь = ждёт вас, красный = остановлено.
