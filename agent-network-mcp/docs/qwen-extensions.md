# Как добавить Qwen extension в плагины Agent Network

Extension объединяет связанные skills и, при необходимости, MCP-серверы. Agent Network показывает установленный
extension как плагин, который координатор может назначить конкретному Qwen-агенту в предложении задачи.

## 1. Проверьте CLI

В терминале пользователя, который запускает Agent Network:

```sh
qwen --version
qwen extensions list
```

Установка пакета и просмотр списка не требуют работающей модели. Для выполнения задач модель понадобится.

## 2. Подготовьте папку

Например, `D:\Plugins\frontend-kit` на Windows:

```text
frontend-kit/
├── qwen-extension.json
└── skills/
    └── ui-review/
        ├── SKILL.md
        └── references/
            └── checklist.md
```

В `qwen-extension.json`:

```json
{
  "name": "frontend-kit",
  "version": "1.0.0",
  "description": "Проверка интерфейсов: формы, адаптивность и доступность."
}
```

Имя должно быть уникальным, начинаться с латинской буквы или цифры и содержать только латиницу, цифры, `.`, `_`, `-`.
Agent Network принимает имена длиной до 128 символов; `none` зарезервировано. Описание помогает координатору
выбрать пакет, поэтому опишите его назначение конкретно.

## 3. Заверните обычные skills

Скопируйте в `skills/` всю папку каждого навыка, включая `references`, `scripts` и `assets`.
Сохраните относительные пути и проверьте инструкции, зависящие от инструментов другого CLI.
Минимальный `skills/ui-review/SKILL.md`:

```markdown
---
name: ui-review
description: Проверять формы, адаптивность и доступность интерфейса.
---

# Проверка интерфейса

Проверь состояния загрузки, ошибки и пустые данные.
Проверь подписи полей и управление с клавиатуры.
Для каждого замечания укажи шаги воспроизведения и ожидаемое поведение.
```

Qwen зарегистрирует этот skill как `frontend-kit:ui-review`. Можно добавить несколько навыков в один пакет,
но небольшие тематические пакеты позволяют точнее выбирать контекст для каждого агента.

## 4. При необходимости добавьте MCP

Пакет только со skills не требует MCP. Если сервер нужен, добавьте поле `mcpServers` в корневой манифест:

```json
{
  "name": "frontend-kit",
  "version": "1.0.0",
  "description": "Проверка интерфейсов со вспомогательными инструментами.",
  "mcpServers": {
    "ui-tools": {
      "command": "node",
      "args": ["D:/Plugins/my-mcp-server/index.js"]
    }
  }
}
```

Это пример структуры: команду и путь замените на свой работающий MCP-сервер. Имя MCP не должно быть
`agent-network`: этот сервер подключается runner'ом отдельно. Не помещайте секреты в описание плагина;
в контекст координатора передаются описания и имена ресурсов, но не команды MCP и их переменные окружения.

## 5. Установите и проверьте

```sh
qwen extensions install "D:\Plugins\frontend-kit"
qwen extensions list
```

На macOS/Linux используйте свой путь, например `qwen extensions install ./frontend-kit`.
Проверьте успешное завершение установки. Qwen устанавливает копию локальной папки.

Откройте **Настройки → Плагины** в Agent Network. Карточка `frontend-kit` появится автоматически.
Включите её, чтобы разрешить координатору выбирать пакет в этом проекте. Для назначения также нужен
настроенный Qwen runner; запускать его для просмотра каталога не требуется.

## 6. Используйте через координатора

Пример запроса: «Подготовь задачу на проверку формы входа. Для Qwen-проверяющего выбери плагин frontend-kit».
Перед подтверждением проверьте «Плагины команды» в предложении. Назначенный набор применяется при запуске
новой сессии. Уже работающая сессия не меняется. Ограничения Qwen и отключённых skills продолжают действовать.

## 7. Обновляйте установленную копию

После изменения исходной папки:

```sh
qwen extensions update frontend-kit
qwen extensions list
```

При изменении манифеста потребуется новая версия предложения задачи: сервер сверяет его хеш с утверждённым.
Изменение исходной папки без обновления установленной копии не применяется к установленному плагину.

## Если плагин не появился

- Проверьте корректность JSON и наличие `~/.qwen/extensions/<папка>/qwen-extension.json`.
- Убедитесь, что Qwen и сервер Agent Network запускаются одним пользователем.
- Каталог Agent Network пока читает именно `qwen-extension.json`; другие форматы манифестов не отображаются.
- Дубли зарегистрированных имён и плагины с MCP `agent-network` не принимаются.
- Страница опрашивает каталог автоматически; можно также обновить её вручную.
- Если нет Qwen runners, карточки можно просматривать, но назначить их агенту другого движка нельзя.
