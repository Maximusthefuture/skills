## ADDED Requirements

### Requirement: Подарочная упаковка
Покупатель SHALL иметь возможность добавить подарочную упаковку к заказу.

#### Scenario: Добавление упаковки
- WHEN покупатель отправляет PUT /orders/{id}/gift-wrap с сообщением
- THEN упаковка добавляется корректно

#### Scenario: Длинное сообщение
- WHEN сообщение длиннее 500 символов
- THEN ошибка
